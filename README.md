## ✦ About

I am a Computer Science graduate specializing in **Artificial Intelligence and Machine Learning**, operating at the intersection of **applied ML research** and **production software engineering**.

I don't treat machine learning models as opaque black-box APIs. My engineering philosophy is built on understanding architectures from first principles—whether that means deriving attention mechanics from scratch in PyTorch, isolating causal prompt failure conditions with Delta Debugging, or decoupling probabilistic LLM content inspection from deterministic policy enforcement.

Alongside building systems, I maintain active research and mathematical rigor—advancing mid-resource neural machine translation with Springer Nature, engineering adversarial evaluation suites (PromptProbe), and currently preparing again for **GATE CSE & GATE DA 2027** to sharpen core theory in linear algebra, probability, and optimization.

🛡️ **Flagship LLM Security System**

### 🛡️ SentinelLLM

**Runtime Security Controls & Adversarial Defense Gateway**

An open-source defense-in-depth security gateway that protects LLM applications and agentic tool-use pipelines against prompt injection, privilege escalation, and untrusted data poisoning. Decouples probabilistic content inspection from deterministic action-level policy enforcement (PEP/PDP). High-risk actions require cryptographically bound supervisor approvals (SHA-256 parameter digests) with row-level locking (`SELECT ... FOR UPDATE`) to prevent TOCTOU tampering.

Includes the **PromptProbe** companion adversarial evaluation harness (23 single cases, 10 multi-step attack scenarios, 95.6% benchmark accuracy, zero unauthorized simulated tool executions). Covered by 264 backend tests and 16 frontend security tests with Mypy strict typing.

`Python 3.12+` `FastAPI` `PostgreSQL 16` `SQLAlchemy 2.0` `Next.js 15` `Docker`

🔬 **Agent Diagnostics & Causal Inference**

### 🔬 AgentXRay

**Causal Failure-Condition Minimization Engine for AI Agents**

An open-source diagnostic engine that isolates the minimal failure-inducing prompt instructions, tool schemas, and environment flags in tool-calling AI agents without inspecting model weights. Adapts Andreas Zeller's Delta Debugging (`ddmin`) algorithm to black-box agent workflows, reducing evaluation calls by 40–70% compared to linear scans ($O(\log N)$ scaling).

Implements rigorous counterfactual verification ($c \setminus \{e\}$) to mathematically prove 1-minimality before reporting culprits. Ships with a typed Python SDK facade (`agentxray.diagnose`), a POSIX CLI with CI/CD regression exit codes (0, 1, 2, 3), and hermetic offline testbeds running in under 15 ms at $0.00 cloud spend. Backed by 640 tests and a live interactive Hugging Face Spaces application.

`Python 3.12+` `Delta Debugging (ddmin)` `CLI & SDK Facade` `Vite` `Gradio`

### ⚡ Kogniq

**High-Performance Document Intelligence Console**

A full-stack RAG console ingesting PDF, LaTeX, Markdown, and TXT research documents with hybrid reciprocal-rank retrieval and strict provenance verification. 📊 **Empirical ML & Robustness Research**

### 📊 CAPTCHA Robustness Analyzer

**Reference-Based Image Degradation & Robustness Evaluation**

A reproducible empirical research repository measuring how controlled visual degradations affect synthetic CAPTCHA-style text images, testing whether conventional image features can predict reference-based structural similarity (SSIM). Evaluates controlled corruption ladders (Gaussian blur, additive noise, thin-line/arc interference, bounded elastic warps) on 192×64 grayscale images.

Trained on 8 handcrafted image features across a matched 10-font benchmark (30 cases, 300 sources) with source-grouped splits. Features fail-closed provenance auditing, dataset integrity verification, deterministic replay workflows, and a versioned v1.0.0 release with 866 passing tests. Accompanied by a live public Streamlit dashboard.

📘 **Peer-Reviewed Deep Learning Research**

### 🤖 S2S Transformer

**From-Scratch Encoder-Decoder NMT Architecture**

A sequence-to-sequence Transformer built from first principles in PyTorch (co-developed) for English-to-Hindi Neural Machine Translation. Implements custom multi-head scaled dot-product attention, sinusoidal positional encodings, and causal decoding masks without relying on high-level prebuilt seq2seq wrappers.

Trained on the 1.6M-sentence IIT Bombay Parallel Corpus using a custom Byte Pair Encoding (BPE) subword tokenization pipeline. Achieved **BLEU 49.37**, **chrF 78.37**, and **METEOR 85.89**, outperforming general-purpose multilingual baselines. Features deep interpretability diagnostics: cross-attention alignment heatmaps, layer-wise entropy profiling, and decoder confidence calibration. Publication-backed.

`PyTorch` `Python` `Custom BPE Tokenizer` `IITB Corpus` `Interpretability`
